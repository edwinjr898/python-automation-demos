# Inka Brasas — Restaurant Marketing Site (Case Study)

**Live site:** [https://inkabrasas.com](https://inkabrasas.com)

End-to-end design, build, and deploy of a modern marketing website for a family-owned restaurant client — Inka Brasas Peruvian Cuisine in Spring, TX. The site drives visits, pickup/delivery orders, and catering inquiries while telling Chef Gladys’s story to English- and Spanish-speaking guests.

> Full private source stays local. This folder is the **public case study** only — no production codebase or media.

---

## Client & goal

| | |
|---|---|
| **Client** | Inka Brasas Peruvian Cuisine — family-owned restaurant, Spring, TX |
| **Goal** | A polished marketing site that converts browsers into diners: dine-in visits, third-party delivery/pickup, catering, and large-party / game-day requests |
| **Role** | End-to-end design + build + deploy |

---

## What shipped

- **Responsive marketing site** — mobile-first layout suited to guests ordering from phones
- **Menu + order paths** — clear routes to Uber Eats, DoorDash, Grubhub, and call-ahead pickup
- **Bilingual EN/ES** — Spanish audience supported alongside English
- **Catering page** — dedicated path for events and group orders
- **Chef story** — brand narrative around Chef Gladys and Peruvian hospitality
- **SEO dish landing pages** — indexable pages for signature dishes and discovery traffic
- **Large-party / game-day request form** — structured lead capture for bigger bookings
- **Netlify deploy** — production hosting with continuous static deploy
