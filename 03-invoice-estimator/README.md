# Invoice Estimator

Vanilla HTML/CSS/JS quote calculator (no build step).

## What it does

- Enter hourly rate, estimated hours, optional rush fee %
- Shows estimated total with base + rush breakdown
- Dark/light theme toggle; works via file:// or simple http.server

## How to open

Open index.html in a browser, or run: python -m http.server 8080

## Sample client tool

Customize branding, currency, tax; embed in a client portal or GitHub Pages.
